📌 About The Project

Rozario Atelier is a modern fashion/lifestyle-inspired web project designed with a strong focus on visual storytelling, elegant UI, and responsive user experience.

The goal was to create a premium digital presence that feels minimal, artistic, and sophisticated while keeping the interface intuitive and easy to navigate.

This project combines my interests in UI/UX Design, Graphic Design, and Front-End Development into one complete web experience.

- Create a premium and elegant brand presence
- Build a clean and visually engaging interface
- Maintain a consistent design system

🎨 Design Direction

The visual direction of Rozario Atelier focuses on:

Elegant · Minimal · Modern · Artistic · Premium

The interface uses balanced spacing, refined typography, strong visual hierarchy, and a clean layout to create a sophisticated brand experience.

📱 Responsive Design

The website is designed to provide a consistent experience across:

- 💻 Desktop
- 📱 Mobile
- 📲 Tablet

The layouts, typography, spacing, and components adapt according to different screen sizes.
